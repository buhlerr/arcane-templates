# Arcane Template Registry

Este repositório contém 361 Docker Compose templates convertidos do Portainer Marketplace (Lissy93) e enriquecidos com metadados nativos **`x-arcane`** (ícones vetoriais temáticos, tags com cores padronizadas e links de documentação).

## Como Usar no Arcane

1. Acesse seu painel do Arcane (`Customization` → `Templates`).
2. Clique em **Add Registry**.
3. Adicione a URL raw da registry:
   ```text
   https://raw.githubusercontent.com/buhlerr/arcane-templates/main/registry.json
   ```
4. Salve para explorar os templates com visual completo!

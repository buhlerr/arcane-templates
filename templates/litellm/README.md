# LiteLLM

LiteLLM proxy - one OpenAI-compatible endpoint in front of every LLM provider (Anthropic, OpenAI, Gemini, Bedrock, Mistral, local, …) with virtual keys, per-key budgets, spend tracking, fallbacks and retries.

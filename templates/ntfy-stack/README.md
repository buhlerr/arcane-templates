# ntfy (stack)

ntfy - push notifications as an HTTP primitive: `curl -d "backup done" https://your-domain/alerts` and every subscribed phone (iOS/Android apps) and browser gets it. Topics, priorities, attachments, scheduled delivery - one tiny Go binary.

Source: https://github.com/binwiederhier/ntfy

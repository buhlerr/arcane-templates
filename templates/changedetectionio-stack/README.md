# changedetection.io (stack)

changedetection.io - watch any web page for changes (prices, stock, content, competitors' pages) with filters, diffs, and notifications to 80+ targets (the in-project `ntfy` template included). Single container, one volume.

Source: https://github.com/dgtlmoon/changedetection.io

- **Categorias:** monitoring-analytics
